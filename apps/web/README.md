# Web App

This app contains the frontend for the monorepo.

## Stack

- React
- TypeScript
- Tailwind CSS
- Vite

## Scripts

Run from `apps/web`:

- `pnpm dev` - start local development server
- `pnpm build` - build production assets
- `pnpm typecheck` - run TypeScript type check
- `pnpm lint` - run ESLint
